# أقساط — تطبيق iOS أصلي (Capacitor)

هذا المجلد يغلّف تطبيق «أقساط» كتطبيق iOS أصلي. التطبيق الأصلي يفتح موقعك
المنشور على Cloudflare مباشرة، فأي تحديث تنشره على `main` يظهر فيه دون إعادة بناء.

السبب: تطبيقات الويب المثبّتة على الشاشة الرئيسية لا تستطيع الرسم داخل عمود الساعة
الجانبي في الآيفون القابل للطي، بينما التطبيقات الأصلية تستطيع (مثل ماسنجر).

## المتطلبات

- جهاز Mac مثبّت عليه Xcode.
- Node.js (الإصدار 20 أو أحدث).
- حساب Apple ID (المجاني يكفي للتجربة على جهازك).

## خطوات التشغيل الأولى

1. اسحب آخر نسخة من المستودع، ثم ادخل المجلد:

   ```bash
   cd Aksat/native
   ```

2. ثبّت الحزم:

   ```bash
   npm install
   ```

3. افتح `capacitor.config.json` وضع رابط موقعك المنشور بدل القيمة المؤقتة في `server.url`
   (مثل `https://aksat.<حسابك>.workers.dev`).

4. انسخ الإعداد إلى مشروع Xcode:

   ```bash
   npx cap sync ios
   ```

5. افتح المشروع في Xcode:

   ```bash
   npx cap open ios
   ```

6. في Xcode: اختر الهدف `App` ← تبويب **Signing & Capabilities** ← في **Team** اختر
   حسابك (Personal Team). إن لم يظهر: Xcode ← Settings ← Accounts ← أضف Apple ID.

7. إن ظهر خطأ بأن معرّف التطبيق مستخدم، غيّر **Bundle Identifier** إلى قيمة فريدة
   (مثل `com.اسمك.aksat` بحروف إنجليزية).

8. وصّل الآيفون بالكابل، وفعّل **وضع المطوّر** عليه:
   الإعدادات ← الخصوصية والأمان ← وضع المطوّر.

9. اختر جهازك من أعلى Xcode واضغط زر التشغيل ▶.

10. أول مرة: على الآيفون افتح الإعدادات ← عام ← إدارة VPN والجهاز ← اختر حسابك ← وثوق.

## قيود الحساب المجاني

- التطبيق يعمل 7 أيام، ثم يحتاج إعادة تشغيله من Xcode (الخطوة 9 فقط).
- إشعارات الويب (التذكير بالأقساط) لا تعمل داخل التطبيق الأصلي.
- لا يمكن نشره على المتجر أو مشاركته.
